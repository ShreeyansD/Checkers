# Checkers

## Project Goal
A two-player checkers game in Java that runs in the terminal, so friends can play without a physical board, downloads, or accounts.

## MVP Scope
- Board display with coordinates
- Move input parsing
- Diagonal movement and alternating turns
- Captures, forced capture rule, and multi-jumps
- Kings (promotion and backwards movement)
- Rejection of illegal moves
- Win detection

## Future Plans (Schedule)
- Undo move feature
- Checkers bot
- Draw offers
- Legal Move highlighting

- ## Tech Stack
- Java
- Java Standard Library only
- Git and GitHub, VS Code and the terminal
